What it does

One phone, two systems

A container-based guest, not full-machine emulation, sharing your host kernel the way Waydroid or Anbox do on desktop Linux.

Real isolation

Linux namespaces and cgroups wall the guest off from the host: its own PID tree, mounts, and (where the host allows it) resource limits.

32-bit that still works

Newer Snapdragons dropped AArch32 entirely. VineOS detects that and drops in a bundled qemu-arm user-mode layer so 32-bit guest apps keep running.

ROMs from anywhere

Pull a verified image from the ROM store, or import a .vrom file straight off your device, no network required.

Root optional

Full namespace containers today need host root. A Shizuku/Wireless-Debugging path is in active research toward running without it.
